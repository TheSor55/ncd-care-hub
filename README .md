## 📋 เกี่ยวกับโครงการ

NCD Care Hub คือนวัตกรรมแอปพลิเคชันดิจิทัลบูรณาการ พัฒนาจากงานวิจัย 2 เรื่อง ได้แก่:

1. **เรื่องที่ 1** — ผลของโปรแกรมการกำกับตนเองต่อพฤติกรรมการสร้างเสริมสุขภาพของกลุ่มเสี่ยงโรคความดันโลหิตสูง *(ประยุกต์ทฤษฎีการกำกับตนเองของ Bandura, 1991)*
1. **เรื่องที่ 2** — การพัฒนาระบบคัดกรองโรคไตเรื้อรังในผู้ป่วยเบาหวานและความดันโลหิตสูงในชุมชน *(อ้างอิง KDIGO 2024)*

## 💡 จุดเด่น

- **ไฟล์เดียว** — HTML + CSS + JS รวมในไฟล์เดียว ไม่ต้องติดตั้ง
- **ออฟไลน์** — ทำงานได้แม้ไม่มีอินเทอร์เน็ต
- **ข้อมูลปลอดภัย** — เก็บใน LocalStorage ของเครื่องผู้ใช้ ไม่ส่งออก Cloud
- **ฟรี** — ไม่มีค่าใช้จ่าย ไม่มี Server
- **ภาษาไทย** — ออกแบบสำหรับบุคลากร รพ.สต. ไทยโดยเฉพาะ
- **Flag ผลแล็บ** — แสดง ↑↓ อัตโนมัติเมื่อค่าเกิน/ต่ำกว่าปกติ
